# v2.5 簡易製図AI（太陽光配置図・ストリングス図 自動生成）

現地調査の手書き資料（手書きスケッチ／航空写真＋赤ペン寸法／建築図面／現地写真）から、
㈱サンエー標準テンプレートの **太陽光配置図** と **ストリングス図** を自動生成する
「簡易製図AI」を、見積作成AIとは別系統のモードとして追加しました。

遠藤さんの要望「現地調査の手書き資料を入力して製図を自動生成」を実装。完成製図を
見積に反映することで、現状・延長時・製造後の3段階の手間削減を狙う機能です。

## 全体フロー

```
現調資料(PDF/PNG/JPG)
   │  spec_extractor.extract_drafting_spec()   ← Claude Vision抽出
   ▼
DraftingSpec（屋根面・モジュール・枚数・系統）
   │  ＜確認・修正フォーム＞                      ← 人が誤読を補正（AI補助方式）
   ▼
   │  layout_engine.place_panels()             ← 複数屋根面のパネル配置を幾何計算
   ▼
   │  drawing_renderer.render_drawing()        ← matplotlibでSANEI標準CAD図面
   ▼
PNG / PDF（A4・A3横）
```

抽出 → **確認フォームで修正** → 製図、の3ステップ。手書き寸法は誤読しうるため、
AIは読めた値のみ反映し、読めない項目は推定せず警告として提示する（幻覚を出さない）設計。

## 対応図面（v2.5スコープ）

- **太陽光配置図 / レイアウト図 / 割付図**（全案件・コア）
- **ストリングス図**（PCS系統別に色分け＋系統表）
- 機器配置図は将来拡張（Equipmentモデルのフックのみ用意）

## 図面テンプレート要素（実サンプル準拠）

屋根外形（矩形／ポリゴン）＋瓦・折板のハッチング、マゼンタのパネル割付（縦置き／横置き）、
赤・緑の寸法線、方位記号、モジュール情報ボックス（割付図／型番／設置容量kW・枚数／PCS）、
架台断面図（屋根用架台／低重心架台／陸屋根用／折板屋根用 の出し分け）、パネル詳細図、
系統表（ストリングス図）、サンエー社名入りタイトルブロック（法人／住宅でラベル出し分け）。

## 技術メモ

- **描画**: matplotlib(Agg)。日本語は `assets/fonts/NotoSansJP-*.ttf` を登録。PDFはベクター出力。
- **抽出**: `extraction/pdf_reader.pdf_to_images` と `extraction/survey_extractor` のClaude呼び出し・JSON抽出を流用。`config.get_api_key()` / `CLAUDE_MODEL`。
- **隙間規約**: 列間（横）=10mm標準、行間（縦）=25mm標準（実図面で一貫）。layout_engine・renderer・パネル詳細図で統一。
- **堅牢性**: APIキー無し／API失敗／JSON不正でも例外を投げず、警告入りの最小specを返し確認フォームへ。1つの不正数値で抽出全体を失わない設計。画像はピクセル寸法(≤4000px)・合計サイズ(≤28MB)で自動調整。

## 品質保証

- 3エンジンを並列構築（Workflow）→ 各自己テスト全パス。
- 4ゴールデンを本番パイプライン（配置→描画）で実サンプルと目視照合（一致度90〜95%）。
- 実サンプル（栗原 現調後PDF）でエンドツーエンド抽出を確認（読めた屋根寸法のみ反映・他は警告）。
- 敵対的コードレビュー（4観点並列）で critical 0 / high 5 / medium 4 / low 11 を検出 → high全件＋主要medium/lowを修正。
- Streamlitヘッドレス起動でエラー無しを確認。

## 既知の制約・申し送り

- ポリゴン屋根の離隔は外接矩形基準の近似（v1）。傾斜辺へのクリアランス厳密化は将来。
- 縮尺はtitle.scale優先、空欄時は作図域から自動推定（原本と差異が出る場合あり）。
- **要確認**: `config.py` の `COMPANY_INFO["address"]` は「三春町2-10」だが、実製図サンプルは「三春町4-1-10」。製図レンダラは実サンプル準拠の4-1-10を使用。見積PDF側(config参照)の住所が正しいか要確認。
