# パネルの隙間・点検通路 用語ルール

株式会社サンエー 御中
（見積もり作成AI・簡易製図AI 共通 ／ 2026年7月23日 改訂）

7/23のお打ち合わせを受けて、パネルとパネルの間隔の呼び方を
**「長辺側隙間」「短辺側隙間」** の2つに統一しました。
画面の入力欄・図面の表記もこの呼び方に揃えています。

---

## 用語は3つだけです

| 用語 | どこの隙間か | 標準の値 |
|------|------------|---------|
| **長辺側隙間** | **段と段の間**（上下方向のすきま） | **25mm**（陸屋根のみ500mm） |
| **短辺側隙間** | **列と列の間**（左右方向のすきま） | **10mm** |
| **点検通路** | **2列ごと**に設ける、人が通るための広い通路 | **800mm**（800〜1,000mmで調整可） |

---

## 図で見ると（屋根を真上から見た図）

```
                 短辺側隙間              点検通路
                 (10mm)                (800mm)
                  ↓↓                 ↓←────→↓
   ┌────┐┌────┐    ┌────┐┌────┐
   │ パネル ││ パネル │    │ パネル ││ パネル │   ← 1段目
   └────┘└────┘    └────┘└────┘
        ↕ 長辺側隙間 (25mm) ＝ 段と段の間
   ┌────┐┌────┐    ┌────┐┌────┐
   │ パネル ││ パネル │    │ パネル ││ パネル │   ← 2段目
   └────┘└────┘    └────┘└────┘

    └─ 2列 ─┘  通路  └─ 2列 ─┘
```

- **長辺側隙間（25mm）**: 上下に並ぶ段どうしのすきま。架台のレールや水はけのために確保します。陸屋根では影対策のため500mmに広がります。
- **短辺側隙間（10mm）**: 横に隣り合うパネルどうしの小さなすきまです。
- **点検通路（800mm）**: 設置後の点検・清掃のときに人が歩くための通路です。2列並べるごとに1本入ります。

---

## 画面での操作について

- 入力欄の名前を「長辺側隙間 (mm)」「短辺側隙間 (mm)」に変更しました。数値の意味・初期値（25mm／10mm）は今までと同じです。
- 「点検通路幅 (mm)」と「通路の間隔（N列ごと）」の入力欄を追加しました。
  - 初期値は **800mm・2列ごと** です。800〜1,000mmの範囲で調整してください。
  - **0** を入力すると通路なし（今までどおりの詰めた配置）になります。
- 通路を入れた図面には、通路の幅（例: 800）が赤い寸法で表示されます。
- 過去に保存した図面・学習データはそのまま使えます（保存時のままの配置で再現されます）。
