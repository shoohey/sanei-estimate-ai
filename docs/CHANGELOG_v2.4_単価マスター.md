# v2.4 産業用部材 単価マスター登録

㈱サンエー様の「産業用部材価格表」PDF（2025-05-30版）を構造化し、
見積作成AIに**単価マスター**として組み込みました。見積編集画面から
価格表を横断検索し、選んだ部材をワンクリックで見積明細に追加できます。

- **出典**: ㈱サンエー様 産業用部材価格表 資料.pdf（2025-05-30・**単価は税抜**）
- **製品数**: 267点 / **メーカー**: 12社 / **カテゴリ**: 5区分

| カテゴリ | 件数 | 主なメーカー |

各レコードのフィールド:

`parent_code`(延長保証の親PCS) / `source_page` / `is_duplicate` / `is_canonical`

### 抽出時の正規化処理
- **文字化け補正**: PDFのCJK部首文字（`⽤→用` `⾃→自` `⾏→行` `⾦→金` 等）をNFKC正規化、
  NFKCで残る `⻑→長` `⻄→西` は明示マップで補正。
- **カテゴリ補完**: PDFのマージセル欠落により失われた「パワコン」「架台」の区分を、
  並び順とJAMコード境界から復元。
- **メーカー補完**: page1末尾のオムロン自家消費ブロックがマージ欠落で`SUNGROW`に
  引き継がれていた誤りを、KPW/KP-型番から`オムロン（自家消費用途）`へ補正。

## 機能（見積編集画面 → 「📋 産業用部材 単価マスター」）

1. **横断検索**: カテゴリ／メーカー絞り込み＋キーワード（型番・品名・商品コード）検索。
2. **一覧表示**: カテゴリ／メーカー／コード／型番／品名／単価／備考のテーブル。
3. **見積へ明細追加**: 部材を選び、数量・単位・追加先カテゴリ・単価（編集可）を指定して
   見積明細にワンクリック追加。小計・消費税・税込合計・表紙金額を自動再計算。
4. **取引条件表示**: 価格表フッターの取引条件（輸送・送料・カーポート納期等）を参照可能。

プログラムからの単価参照は `product.price_master.find_price(maker, model, code)` を利用。

## ⚠️ 重要な要確認事項（オムロン自家消費用途の価格重複）

元PDFには**オムロン（自家消費用途）のPCS群（KPW-A55系ほか31コード）が
2系統の価格で重複掲載**されています（例: `KPW-A55-2PJ4 B0S0011300` が
page1=¥231,000 / page2=¥219,000）。

本ツールでは**両方を保持**した上で、延長保証等を含む網羅的な**後ページ(page2)側を
代表価格(`is_canonical=true`)として採用**しています。UI上でも重複時に注意喚起を表示します。
**どちらの価格を正とするかはサンエー様にご確認ください**（確認後、必要なら
`is_canonical` の採用基準を変更可能）。

## マスターの再生成

価格表PDFが更新された場合:

```bash
python build_price_master.py "/path/to/新しい価格表.pdf"
```

`knowledge/price_master.json` が再生成され、アプリは次回読み込み時に自動反映されます
（mtimeベースのキャッシュ失効）。

- `python build_price_master.py` … 267点抽出・全カテゴリ価格網羅・条件9項目取得
- `python product/price_master.py` … 検索/単価参照 self-test 全パス

- 見積明細追加のE2E検算（数量×単価・備考・根拠・合計再計算・表紙同期）パス

### 並列検証ワークフロー（独立データ突合＋敵対的レビュー・3エージェント）
- **データ整合性**: PDF全267行をJSONと位置対応で全数突合 → unit_price/商品コード/品名/注記すべて**0件不一致（完全一致）**。文字化け・カテゴリ誤り・メーカー誤補完も0件。
- **検出バグを修正済み（critical 0 / high 3 を含む）**:
  - `find_price` がメーカー不一致時に別メーカー価格へ静かにフォールバックする問題 → メーカー指定時は一致無しなら `None` を返す厳格化
  - `find_price` が曖昧な部分一致を確定単価として返す問題 → 型番**完全一致**のみ採用（`allow_fuzzy=False` 既定）
  - 単価入力欄のkey固定により部材切替で前の単価が残る問題 → keyを選択製品IDで分離
  - `search(limit=0)` が1件返すoff-by-one、`format_price` のbool/float誤整形、キャッシュ失効（mtime+size化）、全角型番の正規化、共有キャッシュ汚染 等を修正
  - カーポート運賃（¥0・都度見積）を `null`+注記化し、見積での誤¥0計上を防止
  - 同一ページ内の価格重複を `is_intra_page_duplicate` で明示し、canonical選定を決定的化
